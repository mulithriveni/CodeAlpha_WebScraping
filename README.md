# CodeAlpha_WebScraping
Web Scraping project using Python and BeautifulSoup to extract data from websites, organize it into structured datasets, and perform basic analysis.
# CodeAlpha - Web Scraping

## Objective

To extract data from a website using Python and BeautifulSoup and convert the extracted information into a structured dataset.

## Tools Used

* Python
* Requests
* BeautifulSoup
* Pandas
* Google Colab

## Website Used

https://quotes.toscrape.com

## Data Extracted

* Quotes
* Authors

## Process

1. Sent HTTP request to the website.
2. Parsed HTML content using BeautifulSoup.
3. Extracted quote text and author names.
4. Stored data in a Pandas DataFrame.
5. Exported data to CSV format.

## Output

A structured dataset containing quotes and their authors was generated successfully.

## Conclusion

This project demonstrates the fundamentals of web scraping and data collection using Python libraries.
